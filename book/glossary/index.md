# Glossary of Terms

This glossary contains definitions for key terms used in the Physical AI & Humanoid Robotics textbook.

## A

### AI (Artificial Intelligence)
The simulation of human intelligence processes by machines, especially computer systems. In the context of robotics, AI enables robots to perceive, reason, learn, and adapt to their environment.

### Actuator
A component of a machine that helps create motion. It converts various forms of energy (electrical, hydraulic, pneumatic) into mechanical motion. In humanoid robots, actuators control joint movements.

## B

### Behavior Tree
A mathematical model of plan execution used in robotics and AI. It represents tasks and actions in a tree structure, providing a robust and flexible approach to controlling robot behavior.

## C

### Computer Vision
A field of AI that trains computers to interpret and understand visual information from the world. For humanoid robots, computer vision enables object recognition, navigation, and interaction.

### Control System
A system that manages, commands, directs, or regulates the behavior of other devices or systems. In robotics, this involves algorithms that determine how a robot should move and respond to inputs.

## D

### Deep Learning
A subset of machine learning based on artificial neural networks with representation learning. It can learn multiple levels of representation corresponding to different levels of abstraction.

### DOF (Degrees of Freedom)
The number of parameters that define the configuration or state of a mechanical system. For robots, it typically refers to the number of independent joints or movements.

## E

### Embodiment
The concept that intelligence is determined by the environment an agent interacts with. Physical AI emphasizes the importance of physical embodiment for true intelligence.

## F

### Forward Kinematics
The use of kinematic equations to compute the position of the end-effector from specified values of joint parameters in a robotic system.

## G

### Gazebo
A physics-based 3D simulation environment for robotics. It allows testing of robotics applications without the need for physical hardware.

## H

### Humanoid Robot
A robot with a physical body similar to that of a human, designed to interact with human environments and tools.

## I

### Inverse Kinematics
The mathematical process of calculating the variable joint parameters needed to place the end of a kinematic chain in a given position and orientation.

## J

### Joint Space
The space defined by the joint angles of a robotic manipulator. It is one of the ways to represent the configuration of a robot.

## L

### LIDAR
Light Detection and Ranging. A remote sensing method that uses light in the form of a pulsed laser to measure distances, commonly used for 3D mapping and navigation in robotics.

## M

### Machine Learning
A type of artificial intelligence that enables computers to learn and make decisions from data without explicit programming for every action.

## N

### Navigation Stack
A collection of ROS packages that implement algorithms for local and global path planning, obstacle avoidance, and robot localization.

## P

### Physical AI
A field that combines artificial intelligence with physical systems, focusing on how intelligence emerges through interaction with the physical world.

### PID Controller
A control loop mechanism employing feedback that is widely used in industrial control systems. It calculates an error value as the difference between a desired setpoint and a measured process variable.

## R

### ROS (Robot Operating System)
A flexible framework for writing robot software. It provides services designed for a heterogeneous computer cluster such as hardware abstraction, device drivers, libraries, visualizers, message-passing, package management.

### Reinforcement Learning
A type of machine learning that focuses on how software agents ought to take actions in an environment to maximize some notion of cumulative reward.

## S

### Sensor Fusion
The combining of sensory data or data derived from disparate sources such that the resulting information has less uncertainty than would be possible when these sources were used individually.

### SLAM (Simultaneous Localization and Mapping)
The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

## T

### Trajectory Planning
The process of creating a path that satisfies time, velocity, acceleration, and position constraints. In robotics, it's crucial for smooth and efficient motion.

## V

### VLA (Vision-Language-Action)
A model architecture that combines visual perception, language understanding, and action generation for robotic manipulation tasks.

## W

### Whole-Body Control
A control approach for robots that simultaneously considers all degrees of freedom in the system to achieve multiple objectives in a coordinated manner.
